# Grafiken der Webseite

Alle Webgrafiken liegen in diesem Ordner und werden beim Build automatisch veröffentlicht.

Für den Anwender gilt nur:

1. Grafik mit einem verständlichen Namen bereitstellen.
2. Beim Austausch kurz angeben, an welcher Stelle sie verwendet werden soll.
3. Der interne Dateiname wird beim Einbau festgelegt.

Aktuelle Zuordnung:

- `hero-industrial-hall.jpg` – Foto der historischen Stahlwerks- und Fertigungshalle im Kopfbereich der Startseite

Für einen späteren Austausch des Headerfotos sind neben der Bilddatei die CSS-Referenz, der Cache-Eintrag im Build-Skript, der UI-Regressionstest und die Bildquellendokumentation gemeinsam zu aktualisieren.
