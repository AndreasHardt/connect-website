# Grafiken der Webseite

Alle Webgrafiken liegen in diesem Ordner und werden beim Build automatisch veröffentlicht.

Für den Anwender gilt nur:

1. Grafik mit einem verständlichen Namen bereitstellen.
2. Beim Austausch kurz angeben, an welcher Stelle sie verwendet werden soll.
3. Der interne Dateiname wird beim Einbau festgelegt.

Aktuelle Zuordnung:

- `header.svg` – Grafik in der Kopfzeile der Startseite

Für einen späteren Austausch von `header.svg` sind keine Änderungen am Build-Skript mehr erforderlich. Die Datei wird automatisch übernommen, geprüft und mit einer neuen Cache-Kennung veröffentlicht.
